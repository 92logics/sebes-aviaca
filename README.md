# AVIACA scripted assistant (Sebeș / Vințu de Jos)

This is a 92 Logics prototype. It is not an official city system and it is not a bid.

Buyer: Municipiul Sebeș (Piața Primăriei nr. 1, Sebeș, Alba).

Notice: https://e-licitatie.ro/pub/notices/c-notice/v2/view/100212215

The chat is scripted from that notice, as republished on public notice pages, and from public city pages. It does not invent statistics as the buyer's data. If a question is outside those sources, the assistant refuses it.

Open `index.html` in a browser. No build step. No server. Works offline. No external AI API and no API key.

Contact: cowork@92logics.com
